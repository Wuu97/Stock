# P0｜实验桥接与 V2 数据谱系审计

状态：`IN_PROGRESS — 已发现定向谱系缺口；禁止重跑/回填，直到桥接结论完成`

## 目标与边界

本任务只核验既有本地证据，不训练模型、不回填数据、不重放历史策略，也不改写数据库或 `data/` 研究产物。目标是决定是否需要任何后续实验，而不是预设已有实验失效。

## 验收项 1：新五策略内部可比性

已核验的共同执行条件：

- 五个账户 `competition_v4_ridge_3y_{baseline,kdj,macd,pure,ridge}` 均有 727 个连续 NAV 点，期间为 2023-09-12 至 2026-09-11。
- 执行账户均通过 `large_cap_top5_ridge_3y/v1`：同一 727 日行情哈希 `e978…94ffdc`、PIT universe 哈希 `5ed9…c674c`、ST 证据哈希 `efb4…d311`、费用、T+1、涨跌停、gap gate、固定退出和固定目标名义仓位。
- `full_five_results/competition_v4_ridge_3y_five_strategy_audit.json` 的 dataset、manifest、schedule、prediction SHA-256 与文件实测值相符；预测为 36,350 行，即 727 日 × 50 个 PIT 标的。

阻断项：Ridge 决策谱系尚未与执行 Profile 对齐，见验收项 2。因此五策略的**共同执行层**可比，但不能在此阶段宣称 Ridge 信号的完整 Profile 谱系已闭环。

## 验收项 2：旧四策略与新五策略的桥接

已定位到首个可验证分歧：2023-09-13 的首批买单。

- 旧四策略使用 `large_cap_top5_medium_term/v4`，Profile hash 为 `3e842271…43833`，没有 `feature_warmup_market_binding`。
- 新五策略使用 `large_cap_top5_ridge_3y/v1`，Profile hash 为 `249346c5…49b295`，冻结了 2023-08-15 至 2023-09-11 的 20 个日线热身快照。
- 两个 Profile 的 727 日市场数据、PIT universe、ST、费用、执行和风险绑定相同；热身绑定是已确认的策略输入差异。
- 四条控制策略在新实验均于 2023-09-13 出现旧实验没有的首笔成交。这足以解释收益曲线从起点即发生分叉，不能将旧四策略与新五策略的同名收益直接相减归因于 Ridge。

桥接决策：无需重建股票池、行情或 V2 dataset。下一步只需进行**只读特征/首日决策桥接复核**：证明旧 Profile 缺热身是否为所有首日分歧的充分原因；只有该复核不能解释后续差异时，才立项一次使用 `ridge_3y/v1` Profile 的四控制策略重放。

## 验收项 3：V2 dataset、预测及 PIT 谱系

已核验：

- `ridge_v4_unified_dataset_v2.parquet` SHA-256 为 `8538…7bad`，manifest 为 `0104…16af4`；60,600 行、1,212 个决策日、每日至少/恰为 50 标的，60,290 行成熟标签、250 行未成熟、60 行不可交易结果。
- 成熟标签不存在 `label_available_trade_date <= trade_date` 的因果违规。
- `full_ridge_schedule_v2.json` 的 13 个模型文件均与各自 `model_sha256` 一致；预测文件的 36,350 个 `(date,ticker)` 键唯一，且每个执行日恰有 50 条预测。

已发现的具体缺口（不是数据回填缺口）：

- `full_ridge_schedule_v2.json` 和 `full_ridge_predictions_v2.jsonl` 记录的 Profile 为 `large_cap_top5_medium_term/v4` / `3e842…43833`。
- 五策略实际执行使用 `large_cap_top5_ridge_3y/v1` / `249346…49b295`，后者新增 20 日热身绑定。
- `scripts/run_full_five_strategy.py` 校验 dataset/schedule/prediction 哈希，但不校验 schedule/prediction 的 Profile hash 是否等于执行 Profile。

结论：V2 数据覆盖、哈希、模型和标签 PIT 边界目前通过；但 Ridge 信号的**Profile 绑定不一致**。执行器现已 fail-closed：父/执行 Profile hash 不同时，只有同时绑定父 hash、执行 hash、预测 artifact hash 和 schedule hash 的显式桥接声明才能放行；任意不匹配均拒绝。该修复不重放 V4，也不修改冻结产物。

全覆盖桥接证据：按实际 `ridge_3y/v1` 热身行情和每日 50 个 PIT 标的，重算 727 日、36,350 个 Ridge 分数。36,100 条（722 日）在 `1e-15` 容差内与冻结预测一致，且所有日期均有 50 个可用特征。最后五日 2026-09-07 至 2026-09-11 的 250 条记录与同一 `full_w13` 模型重算值存在完全相同的固定偏移 `0.01575221647477`；它在每个交易日的全部 50 个标的相同，故不改变当日排序、top-N 或冻结回放产生的订单，但这些绝对分数不能标记为精确复算一致。
