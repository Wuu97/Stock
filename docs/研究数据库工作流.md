# 研究数据库工作流

生产模拟与长时间研究使用不同的 DuckDB 文件。

```text
data/top50/quant.duckdb
  日终流水、前向模拟、生产看板

data/research/*.duckdb
  历史回测、参数实验、策略对照
```

研究库只能由 DuckDB 的 `EXPORT DATABASE` / `IMPORT DATABASE` 生成，不能直接复制正在使用的生产数据库文件。快照命令会以生产库写锁建立静默窗口；若日终任务仍在写入，会安全失败而不是导出不一致数据。

```bash
PYTHONPATH=/private/tmp/quant_audit_deps:. .venv/bin/python \
  scripts/create_research_snapshot.py \
  --production-db data/top50/quant.duckdb \
  --research-db data/research/research_YYYYMMDD.duckdb
```

研究库包含 `research_snapshot_metadata`，其中保存生产库哈希和导出清单哈希。策略研究脚本应只传入该研究库。

## 开盘缺口门禁对照

`run_open_gap_guard_study.py` 会在研究库中运行四个独立账户；它们使用相同的行情、PIT 股票池、策略、费用、仓位和退出规则，只改变开盘门禁：

| 场景 | 高开拒绝 | 低开拒绝 |
| --- | ---: | ---: |
| none | > 1000% | < -99% |
| wide | > 5% | < -6% |
| default | > 3% | < -4% |
| conservative | > 2% | < -3% |

```bash
PYTHONPATH=/private/tmp/quant_audit_deps:. .venv/bin/python \
  scripts/run_open_gap_guard_study.py \
  --db data/research/research_YYYYMMDD.duckdb \
  --start-date YYYY-MM-DD --end-date YYYY-MM-DD \
  --benchmark-close-csv data/ml_history/000300_SH_adjusted_closes.csv \
  --universe-group-name historical_large_cap_momentum \
  --output-dir data/research/reports/open_gap_study
```

研究结论只适用于快照覆盖的样本区间。样本不足时，报告用于观察方向，不得改变生产门禁默认值。
