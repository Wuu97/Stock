## P1 实施顺序

1. 已新建通用、版本化的预测标签契约：`quant_core/prediction_labels.py` 定义 horizon、收益口径、benchmark、上涨阈值、最大回撤定义、标签可得日期和不可交易处理，并由 `tests/test_prediction_labels.py` 覆盖。
2. 已扩展新的 PIT dataset 构建路径：`build_multihorizon_cross_sectional_dataset` 和 `scripts/build_prediction_dataset.py` 可建立独立 schema 的 T+5/T+10/T+20 收益、上涨分类、路径最大回撤标签；既有冻结 T+5 builder/artifact 不变。后续需为每种 label 增加未来数据扰动与可得性单测，并生成首个 research artifact。
3. 已新增模型无关的 `quant_core/prediction_evaluation.py`：回归 MAE/RMSE/Rank IC、概率 Brier/Log loss/校准桶、回撤 MAE 与阈值 precision/recall。`quant_core/multitarget_walk_forward.py:walk_forward_multitarget` 按 horizon 分别训练 Ridge 收益/回撤和线性 Logistic 概率研究基线，逐窗口以对应 `t{H}_label_available_trade_date` 截断训练集；`scripts/run_p1_multitarget_walk_forward.py` 只写新报告并拒绝覆盖已有 artifact。
4. 修复并测试 LightGBM 的标签可得性截断后，才允许将它列入候选模型比较；它不自动晋级到影子或模拟账户。
5. 每一个候选模型先生成冻结的预测评估 artifact，再由严格模拟回放独立验证执行结果。

## 验收标准

- 每个预测输出有明确 `as_of`、horizon、标签定义、label-available date、输入/模型/评估 artifact hash。
- 所有训练样本在预测决策日之前已经具备标签；测试覆盖未来数据变动不会改变历史特征或训练资格。
- 概率输出报告 Brier、Log loss、校准曲线；回撤输出报告覆盖率与校准/分位数诊断；收益输出报告误差、IC/Rank IC 和置信区间。
- 预测质量报告与严格交易回放报告分离，并明确后者才包含费用、T+1、涨跌停、停牌和组合约束。
- 任何 P1 模型默认停留在 `RESEARCH`；进入 `SHADOW` 由 P2 的注册与审批机制决定。

## OOS 验收结果（2026-09-21）

- `v5` 的跨日期 pooled 相关系数曾误标为 Rank IC；冻结原报告不改。新报告 `data/research/ml/p1_multihorizon_walk_forward_20260921_v6.json` 将其更名为 `pooled_rank_correlation`，主口径为逐日横截面 `daily_rank_ic_mean` 及 Bartlett HAC 95% 区间。
- T+5 / T+10 / T+20 的日均 Rank IC 为 **0.0158 / -0.0120 / -0.0249**，对应 HAC 区间均覆盖零。收益平方损失相对零预测的日均差为正（更差）；概率 Brier 损失相对训练期胜率基准虽有微小改善，但不能构成策略晋级证据。
- `daily_mean_error_hac_95` 仅检验日均预测误差是否存在系统性偏差，**不是预测能力检验**；预测能力由日度 Rank IC、基准损失差、校准和后续合格候选的严格执行回放共同判断。
- 上涨概率 Brier 为 0.2498 / 0.2509 / 0.2501，接近无信息 0.25 参考值；报告含 Log loss 与校准桶。最大回撤 MAE 为 0.0360 / 0.0501 / 0.0709，报告含 5%/10%/20% 阈值 precision/recall。
- 回撤标签和预测指标均为**收盘价路径最大回撤**（决策收盘至 horizon 收盘、含端点），不是盘中最大回撤。因为候选模型未通过预测质量门槛，未启动严格交易回放；这符合“研究预测评估与执行回放分离、仅合格候选进入下一关”的受控晋级规则。没有账户、订单、NAV 或策略配置被修改。
